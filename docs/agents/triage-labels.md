# Triage Labels

Engineering skills use five canonical triage roles. Each role maps to the
same-name GitHub label in this repository.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | Reporter information or evidence is required. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and independently executable by an agent. |
| `ready-for-human` | `ready-for-human` | Human implementation or authority is required. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

When a skill names a canonical role, use the mapped tracker label. Do not
invent an alias or a second triage vocabulary.
